# BMW DS2 Диагностика

Веб-приложение для диагностики старых BMW (E30 / E34 / E36, примерно до 2001 г.) по протоколу DS2 через K-line.
Неофициальный проект, не связан с BMW AG.

## Что нужно
- USB-кабель KKL 409.1 или K+DCAN (лучше на чипе FTDI). ELM327 не подходит.
- Переходник 20-pin → OBD2 (контакты 7 и 8 замкнуты).
- Chrome или Edge на компьютере.

## Возможности
- Автоскан блоков управления
- Идентификация блока
- Чтение и стирание ошибок с расшифровкой и рекомендациями (коды Motronic)
- Поток данных с графиком
- Ручные DS2-команды, журнал обмена
- Демо-режим без машины
